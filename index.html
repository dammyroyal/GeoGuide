GEOLOGICAL FIELD TOOLS

Field Tools & Calculators

Scientifically calibrated calculators for map scaling, coordinate conversions, traverses, slope gradients, and structural geology.

Actual Ground Distance —
Formula: Ground distance = Map distance × Scale denominator

Distance to Draw on Map —
Formula: Map distance = Ground distance ÷ Scale denominator

Representative Fraction (Scale) —
Formula: RF denominator = Ground distance ÷ Map distance

Decimal Degrees —
Formula: Decimal degrees = Degrees + (Minutes / 60) + (Seconds / 3600)

Southern (S) and Western (W) coordinates are negative; Northern (N) and Eastern (E) are positive.

Latitude (DMS) —
Longitude (DMS) —
Method: Whole degrees, then fractional degrees × 60 for minutes, remaining fractional minutes × 60 for seconds.

Formatted to standard geological notation with hemisphere identifiers (N/S, E/W).

Horizontal Distance —
Vertical Elevation Change —
Formulas: Horizontal distance = Slope distance × cos(angle)
Vertical change magnitude = Slope distance × sin(angle)

Note: This calculation assumes the measured slope distance and angle describe the same straight traverse segment.

Signed Elevation Change —
Absolute Elevation Difference —
Formula: Elevation change = Ending elevation − Starting elevation

Slope Angle —
Gradient Percentage —
Gradient Ratio (1:n) —
Formulas:
Slope angle = arctan(|vertical difference| ÷ horizontal distance)
Gradient percentage = (|vertical difference| ÷ horizontal distance) × 100
Gradient ratio = 1 : (horizontal distance ÷ |vertical difference|)

Standard Linear Notation —
Trend Direction —
Plunge Inclination —

Trend represents the horizontal azimuth bearing of a line's downward direction, and plunge is its angle below the horizontal. Lineations (striae, fold hinges, mineral stretching) are linear features distinct from planar strike and dip.
